Instructor Guide

Using Exploring Statistics with R

A general guide to the workbook formats, student workflow, starter files, solutions, and instructional support.

Exploring Statistics with R is a companion workbook for Exploring Statistics: Tales of Distributions. It preserves the textbook’s research questions and statistical emphasis while giving students a structured way to conduct the analyses in R.

Intended Audience

The workbook is written for students in an introductory statistics course, including students with no prior programming experience. It may also support instructors who are new to using R in an introductory course.

The R instruction is intentionally selective. Students learn the code needed to complete and understand each statistical analysis, but the workbook is not designed as a comprehensive programming course.

Available Formats

The Quarto source supports two primary formats:

  • HTML provides navigation, searchable content, code-copy controls, and expandable material where appropriate.
  • Word provides an editable and printable document that can be distributed through a learning-management system.

Required instructional content should remain available in both formats. HTML-only interaction is not necessary to complete an activity. In Word, solutions should appear in a final Check Your Work section so students encounter the questions before the sample answers.

Links between workbook pages remain clickable in HTML. Because Word chapters may be downloaded or distributed as separate files, those internal website links appear as readable text in Word rather than as links tied to one computer’s file location. External web links remain clickable in both formats.

Generate HTML And Word Files

The editable workbook pages are the .qmd files in the project folders. To generate new files after editing them:

  1. Install R, RStudio, and Quarto, then open exploring-statistics-r.Rproj.
  2. Run scripts/00-open-and-check-data.R once to install the required R packages and confirm that the data open correctly.
  3. To rebuild the complete HTML website, select Render Website in RStudio or run quarto render from the project folder. The finished website is saved in _site.
  4. To rebuild the complete collection of Word documents, run python tools/render_word.py from the project folder. The finished documents are saved in output/word. This helper requires Python and the lxml package; if Python reports that lxml is missing, run python -m pip install lxml once and try again.

The project already includes rendered HTML and Word files, so instructors only need these steps when they edit the Quarto sources. Keep the project folders together so the data, images, setup file, and Word formatting file remain available during rendering.

Suggested Student Path

Students new to R should complete the four Start Here pages before Chapter 1:

  1. Choose Your Path.
  2. Set Up RStudio.
  3. Run Your First Script.
  4. Understanding EAMMi2.

Students with prior R experience may review the starter-file instructions, run the setup check, and begin Chapter 1.

Each chapter uses a consistent routine:

  1. identify the research question and variables;
  2. plan what the analysis must show;
  3. predict a feature of the output;
  4. run the analysis in the chapter script;
  5. inspect tables, figures, or model output;
  6. write a statistical interpretation; and
  7. compare the work with the final Check Your Work section.

Starter Files

All students need the starter files. The folder contains the RStudio project, EAMMi2 teaching data, shared setup file, chapter scripts, and survey documentation.

Ask students to:

  • unzip the complete folder;
  • keep its contents together;
  • begin each session by opening exploring-statistics-r.Rproj; and
  • run chapter scripts one section at a time while reading the matching workbook chapter.

The shared setup file prepares the R tools used throughout the workbook, including tidyverse, and creates the main data frame named eammi. Package installation is handled there so chapters can remain focused on statistical analysis.

Chapter 15 also uses PMCMRplus to conduct the DSCF post hoc comparisons that follow a significant Kruskal-Wallis test. The setup file installs and loads this package automatically. Students do not need to install or load it separately. If package installation is restricted on institution-managed computers, install PMCMRplus before distributing the starter files or ask the institution’s technical support team to make it available.

Scaffolding Across Chapters

Support fades as students encounter repeated R patterns:

  • The opening materials and Chapters 1–2 use complete examples, explicit navigation, and immediate output checks.
  • Chapters 3–5 ask students to adapt familiar summaries and plots after a worked example.
  • Chapters 6, 9, and 10 place more emphasis on choosing a model and reading its output.
  • Chapters 11–15 provide structured multi-step workflows while asking students to reuse established code patterns more independently.

New R structures should still receive full explanation when they first appear. Later placement in the workbook does not make an unfamiliar command self-explanatory.

Using Practice And Check Your Work

Practice activities may be completed individually, in pairs, or as guided class work. A useful sequence is:

  1. ask students to identify what they will copy from the worked example;
  2. have them mark the object and variable names that must change;
  3. ask them to predict one output feature;
  4. let them run and revise their analysis; and
  5. delay the Check Your Work section until they have written an interpretation.

Sample answers demonstrate an acceptable analysis and interpretation. They are not necessarily the only defensible wording, particularly when students are asked to describe a graph or discuss a data decision.

Supporting Novice R Users

When a student encounters an error, ask for:

  • the script and section being used;
  • the exact code that was run;
  • the first complete error message;
  • the expected result; and
  • what appeared instead.

Encourage students to use the workbook’s Troubleshooting page and restart the analysis from a clean R session when the sequence of previously run code is unclear.

Accessibility

The HTML site uses semantic headings, keyboard-accessible navigation, descriptive links, and text explanations alongside figures. Figures should include captions, meaningful alt text, and readable axis labels. Important distinctions should never depend on color alone.

The pane screenshot is accompanied by a text table and numbered directions. Students should be able to complete the setup without interpreting the image.

For Word distribution, check heading structure, table headers, alternative text, page breaks, and the placement of Check Your Work after every render.

Adapting The Materials

Instructors may adjust pacing, assign only selected research questions, or demonstrate early examples in class. When modifying student code, preserve these conventions:

  • use the native pipe |>;
  • keep the main data frame named eammi;
  • keep meaningful statistical and plotting code visible;
  • use readable object names with underscores;
  • retain consistent category labels and ordering; and
  • explain new syntax before students need to adapt it.

The R Command Index records where commands are first taught and can help instructors avoid introducing later code patterns without preparation.
